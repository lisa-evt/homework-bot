# Homework Status Bot

Telegram-бот для отслеживания статуса проверки домашних работ на платформе Яндекс Практикум.

---

## Описание

Бот раз в 10 минут опрашивает API сервиса Практикум Домашка, проверяет статус отправленной на ревью домашней работы и отправляет уведомление в Telegram при изменении статуса. Все важные события и ошибки логируются и дублируются в Telegram.

---

## Функциональность

- Периодический опрос API Практикум Домашка (раз в 10 минут)
- Отправка уведомлений в Telegram при изменении статуса домашней работы
- Логирование всех событий с указанием даты, времени и уровня важности
- Уведомление о критических ошибках через Telegram

---

## Переменные окружения

Перед запуском создайте файл `.env` в корне проекта и заполните следующие переменные:

```
PRACTICUM_TOKEN=<токен доступа к API Практикума>
TELEGRAM_TOKEN=<токен вашего Telegram-бота>
TELEGRAM_CHAT_ID=<ID вашего Telegram-чата>
```

Получить токены:
- **PRACTICUM_TOKEN** — в личном кабинете Яндекс Практикум
- **TELEGRAM_TOKEN** — у @BotFather в Telegram
- **TELEGRAM_CHAT_ID** — у @userinfobot в Telegram

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone git@github.com:lisa-evt/homework-bot.git
cd homework-bot
```

### 2. Создать и активировать виртуальное окружение

```bash
python -m venv venv
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Создать файл `.env` и заполнить переменные окружения

```bash
cp .env.example .env
# отредактируйте .env, указав свои токены
```

### 5. Запустить бота

```bash
python homework.py
```

## Описание функций

| Функция | Описание |
|---|---|
| `main()` | Основная логика: опрос API → проверка ответа → отправка уведомления → ожидание |
| `check_tokens()` | Проверяет наличие всех необходимых переменных окружения |
| `get_api_answer(timestamp)` | Делает запрос к API и возвращает ответ в виде Python-объекта |
| `check_response(response)` | Проверяет соответствие ответа API документации |
| `parse_status(homework)` | Извлекает статус работы и возвращает строку для отправки в Telegram |
| `send_message(bot, message)` | Отправляет сообщение в Telegram-чат |

---

## Логирование

Каждая запись в журнале содержит:
- дату и время события
- уровень важности (`DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`)
- описание события

Критические ошибки дополнительно отправляются сообщением в Telegram.
